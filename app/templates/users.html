Phone notifications (ntfy logins)

Each user only receives reminders for their own entries, on their personal topic. A user created above only has a website login. For phone notifications they also need an ntfy login. Create it over SSH in the project folder on the NAS (the first command asks for a password twice):

{% for u in users %}{% if not u.disabled %}

{{ u.username }}

sudo docker exec -it certtracker-ntfy ntfy user add {{ u.username }}
sudo docker exec certtracker-ntfy ntfy access {{ u.username }} {{ topics[u.id] }} read-only
{% endif %}{% endfor %}

Once only, the app's publisher account must be allowed to post to every personal topic:

sudo docker exec certtracker-ntfy ntfy access publisher '{{ base_topic }}-*' write-only

If an ntfy user already exists, skip the "user add" line. Forgotten password: sudo docker exec -it certtracker-ntfy ntfy user change-pass NAME
